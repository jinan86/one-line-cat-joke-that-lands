Entry for the [make.fun competition "The One-Line Cat Joke That Lands"](https://make.fun/c/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).

## What it does

`main.py` writes a single one-line joke about a cat to `entry.txt`.
That is the whole program: one fixed string, written out exactly,
so every run produces the same bytes.

## The joke

> The vet asked if my cat had any allergies. She sneezed at the invoice.

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`. Point it elsewhere
for a local check with `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/cat-joke-out python3 main.py
```
